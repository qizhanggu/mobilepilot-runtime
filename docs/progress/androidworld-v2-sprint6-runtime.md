# AndroidWorld Sprint 6：Agent Runtime V2

日期：2026-08-04

状态：**代码与离线测试完成，尚未用本 Sprint 结果宣称 AndroidWorld 收益。**

## 这一阶段解决什么

V1 遇到非法输出、动作失败或明显循环时，通常直接结束或继续消耗步数。V2 把主循环改为一个有界闭环：

```text
观察 → 单步决策 → 协议检查 → 执行 → 局部验证
  ↑                                      ↓
  └──── 按需 UI Tree ← 一次有限 replan ← 失败信号
```

AndroidWorld 官方 reward 仍是唯一最终成功判定。页面指纹变化只是局部进展信号，不能替代官方结果。

## 模块与真实职责

| 模块 | 负责什么 | 不负责什么 |
| --- | --- | --- |
| `Protocol Guard` | 无歧义格式归一化、schema 检查、一次结构化重试 | 不猜 TYPE 文本，不把格式修复称为推理 |
| `RuntimeProgress` | 保存最近已执行动作、当前子目标、阻塞原因和下一步验证 | 不做长期记忆或向量检索 |
| `Loop Detector` | 检测三次相似动作、ABAB 动作循环、两次页面无变化和页面回访 | 不根据任务 ID 编写特例 |
| `RecoveryController` | 每题最多一次 replan，记录是否换动作、是否执行、是否被官方 reward 救回 | 不无限重试，不原样重复执行结果不确定的动作 |
| `UI Tree Tool` | 在视觉不确定、非法输出、动作失败或循环后按需获取结构信息 | V2 不再每步把 Tree 放进上下文 |
| `Verifier` | 记录局部页面变化、预期结果和官方 reward | 不允许模型自报完成替代官方 reward |

## 安全边界

- 非法输出重试前必须没有执行设备动作；每题最多使用一次结构化重试。
- 动作执行失败后先重新观察；Recovery 若再次提出相同动作，直接停止。
- 每题最多一次 Agent Recovery。第二次失败信号只记录并终止，避免无限循环。
- TYPE 内容不会复制进短期进度摘要；Trace 仍保留原始模型证据用于本地审计。
- `v1` 路径保留原 Prompt、每步 Tree 行为和失败即停语义，用于同代码版本内的公平配对。

## 可统计 Trace 事件

- `protocol_guard`：本地归一化、重试触发、重试成功或失败；
- `progress_state`：已完成动作、当前子目标、阻塞和下一步验证；
- `loop_detected`：具体循环信号；
- `agent_recovery_triggered/replan/outcome`：触发、是否换动作、官方救回和误触发；
- `ui_tree_tool_requested/decision/outcome`：调用原因、摘要、是否改变动作及最终官方结果；
- `official_reward`：每轮环境判定及是否终止。

## 离线验证

完成 114 项测试，其中新增覆盖：

- 缺括号 CLICK 与破损 OPEN_APP 的安全归一化；
- 空响应、未知动作的 taxonomy；
- 非法输出只重试一次且重试前无动作；
- V1 保持首次非法输出即结束；
- 重复动作与 ABAB 循环检测；
- 动作失败后重新观察、请求 Tree 并改用不同动作；
- 模型主动请求 UI Tree；
- Recovery 官方救回与误触发统计；
- 官方拒绝模型完成提议后，阻塞状态进入下一轮 Prompt。
