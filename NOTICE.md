# Notice

This repository was assembled from a Mobile GUI Agent entry developed for a ZTE competition.

The competition starter package supplied the agent interface, local evaluation runner,
visualization utility, and offline task format. The project-specific work in this
repository includes the agent decision flow, prompt design, visual grid grounding,
output parsing, coordinate post-processing, experiment analysis, and public-facing
documentation.
